# systemd fuck-up assessment form

To be filled by anyone who fucks up using systemd.

## Building

Install [mkosi](https://github.com/systemd/mkosi) and its host dependencies, then
run from this directory:

```sh
mkosi build
```

The single-page US Letter PDF is written to [mkosi.output/form.pdf](mkosi.output/form.pdf).
